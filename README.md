# RescueMe – Towing Van / Vehicle Service Abuja

24/7 emergency towing PWA for Abuja.

## Features
- Large one-tap **Call** button
- Auto GPS + neighborhood name
- Optional drop-off
- Pre-filled WhatsApp job request (with Google Maps link)
- Clean professional design (Taylor Weld inspired)
- Full PWA: installable on Android + iOS
- Offline-ready via Service Worker
- Compressed images (WebP + JPEG)

## Structure
```
rescume-v2/
├── index.html          ← Main app
├── manifest.json       ← PWA manifest (all devices)
├── sw.js               ← Service Worker
├── README.md
├── icons/
│   ├── icon-48.png … icon-512.png
│   └── icon-maskable-512.png
└── images/
    ├── work1.webp / .jpg
    ├── work2.webp / .jpg
    └── … (8 work photos, 800×500)
```

## Deploy
1. Upload the entire folder to Netlify / Vercel / Cloudflare Pages / GitHub Pages
2. Or open `index.html` locally to test
3. On phone: open the site → browser menu → “Add to Home Screen” / “Install app”
